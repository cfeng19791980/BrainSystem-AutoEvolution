### 2. 短期记忆

**文件**: `.brain_memory.json` → `short[]`

**结构**:
```json
{
  "short": [
    {
      "round_id": 1,
      "user_input": "问题",
      "agent_output": "回答",
      "decision_id": "d_xxx",
      "timestamp": "2026-04-20T..."
    }
  ]
}
```

**特点**:
- ✅ 存储最近对话轮次
- ✅ 关联决策ID
- ❌ 无自动清理机制（会无限增长）
- ❌ 无重要性评分

**建议优化**:
```python
# 添加短期记忆清理
MAX_SHORT_MEMORY = 100  # 最大保留100条

def clean_short_memory():
    if len(short_memory) > MAX_SHORT_MEMORY:
        # 保留最近50条 + 高重要性50条
        recent = short_memory[-50:]
        important = sorted(short_memory[:-50], 
                          key=lambda x: x.get('importance', 0), 
                          reverse=True)[:50]
        return recent + important
```

### 3. 长期记忆

**文件**: `.brain_memory.json` → `long{}`

**结构**:
```json
{
  "long": {
    "preference": [],  // 用户偏好
    "fact": [          // 知识事实
      {
        "memory_id": "kb_xxx",
        "memory_type": "fact",
        "content": "知识内容",
        "keywords": ["关键词"],
        "weight": 5,
        "access_count": 1,
        "source": "import"
      }
    ]
  }
}
```

**当前状态**:
- ✅ 分类存储 (preference/fact)
- ✅ 权重系统 (weight)
- ✅ 访问计数 (access_count)
- ✅ 来源标记 (source)
- ❌ **667KB文件过大** (需要优化存储)
- ❌ 无遗忘机制

**建议优化**:
```python
# 长期记忆遗忘曲线
def apply_forgetting_curve():
    for memory in long_memory['fact']:
        age = days_since(memory['timestamp'])
        access = memory['access_count']
        
        # 遗忘公式: weight = base_weight * (1 - age/365) + access * 0.1
        memory['weight'] = max(1, memory['weight'] - age/365 + access * 0.1)
        
        # 删除权重过低的记忆
        if memory['weight'] < 1:
            delete_memory(memory['memory_id'])
```

## 四、问题诊断

### 问题1: 长期记忆文件过大
- **现状**: `.brain_memory.json` 667KB
- **影响**: 加载慢、内存占用高
- **建议**: 
  1. 分文件存储 (`long_fact.json`, `long_preference.json`)
  2. SQLite替代JSON
  3. 定期清理低权重记忆

### 问题2: 短期记忆无清理
- **现状**: `short[]` 无限增长
- **影响**: 文件膨胀、检索效率下降
- **建议**: 
  1. 最大100条限制
  2. 滑动窗口清理
  3. 重要性评分机制

### 问题3: 经验教训未自动化
- **现状**: 手动记录，无自动关联
- **影响**: 重复犯错，教训利用率低
- **建议**: 
  1. 自动提取失败模式
  2. 操作前检查相关教训
  3. 失败自动生成教训记录

### 问题4: 知识图谱利用率低
- **现状**: 图谱已构建但检索少
- **影响**: 图谱价值未发挥
- **建议**: 
  1. 每次决策强制图谱检索
  2. 图谱可视化界面
  3. 实体自动发现

### 问题5: 多Agent协作未激活
- **现状**: 共享机制存在但使用少
- **影响**: 知识孤立、协作效率低
- **建议**: 
  1. 定期同步任务
  2. 协作仪表盘
  3. 冲突解决机制
