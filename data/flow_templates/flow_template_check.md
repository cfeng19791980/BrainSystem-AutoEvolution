# 检查流程模板

## 触发条件
关键词: 检查, check, 查看, 诊断, inspect, 状态

## 标准流程

### Phase 1: 系统扫描
1. 检查服务状态
2. 检查配置文件
3. 检查日志文件

### Phase 2: 数据分析
1. 查询数据库状态
2. 检查向量索引
3. 检查缓存状态

### Phase 3: 问题识别
1. 对比正常状态
2. 发现异常指标
3. 列出潜在问题

### Phase 4: 建议生成
1. 生成修复建议
2. 优先级排序
3. 提供执行路径

## 输出格式
```
检查报告:
- 系统状态: {status}
- 异常项: {issues}
- 建议: {recommendations}
- 优先级: {priority_list}
```

## 自动触发条件
- 置信度 >= 0.8
- 优先级: medium
- Need Brain: true
