# 修复流程模板

## 触发条件
关键词: 修复, fix, bug, 错误, 问题, 解决

## 标准流程

### Phase 1: 问题定位
1. 分析错误日志
2. 查找相关代码
3. 确定问题根因

### Phase 2: 备份
1. 创建备份目录
2. 备份受影响文件
3. 记录备份路径

### Phase 3: 修复执行
1. 编写修复代码
2. 测试修复效果
3. 验证副作用

### Phase 4: 验证
1. 运行相关测试
2. 检查系统健康
3. 确认问题解决

## 输出格式
```
修复报告:
- 问题: {issue}
- 修复方案: {solution}
- 备份路径: {backup_path}
- 验证结果: {verify_result}
```

## 自动触发条件
- 置信度 >= 0.85
- 优先级: high
- Need Brain: true
