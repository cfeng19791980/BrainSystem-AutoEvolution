# 测试流程模板

## 触发条件
关键词: 测试, test, 验证, 检查, 工程师

## 标准流程

### Phase 1: 预检查
1. 检查系统状态 (`/health`)
2. 查看最近日志
3. 确认备份存在

### Phase 2: 测试执行
1. 编写测试脚本
2. 执行测试用例
3. 收集测试结果

### Phase 3: 结果分析
1. 汇总成功率
2. 分析失败原因
3. 生成测试报告

### Phase 4: 反馈记录
1. 记录测试结果到Feedback DB
2. 更新Pattern统计
3. 生成优化建议

## 输出格式
```
测试报告:
- 测试项: {count}
- 成功: {pass}
- 失败: {fail}
- 建议: {recommendations}
```

## 自动触发条件
- 置信度 >= 0.9
- 优先级: high
- Need Brain: true
