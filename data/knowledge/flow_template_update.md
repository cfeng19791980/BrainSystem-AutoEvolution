# 更新流程模板

## 触发关键词
- 更新、update、刷新、同步

---

## 执行流程

### Step 1: 获取最新版本
```
1. 检查远程数据源/API
2. 检查版本号/时间戳
3. 确认需要更新的内容
```

### Step 2: 备份当前版本
```bash
copy <file> <file>_backup_<version>
```

### Step 3: 应用更新
```
1. 更新数据文件
2. 更新代码文件
3. 更新配置文件
```

### Step 4: 验证更新结果
```
1. 检查版本号/时间戳更新
2. 检查数据完整性
3. 检查功能正常
```

### Step 5: 记录更新内容
```
更新 memory/<date>.md:
- 更新来源
- 更新版本
- 更新时间
- 更新内容摘要
```

---

## 数据更新检查
```
数据文件更新需检查:
1. 时间戳是否最新
2. 数据量是否正常
3. 数据格式是否正确
4. 数据完整性检查
```

---

## 代码更新检查
```
代码文件更新需检查:
1. 版本号是否更新
2. 新功能是否可用
3. 旧功能是否正常
4. 依赖是否更新
```
