# 添加流程模板

## 触发关键词
- 添加、add、新增、创建、增加

---

## 执行流程

### Step 1: 确认添加目标位置
```
1. 确认添加到哪个文件/模块
2. 确认添加位置（文件末尾、特定函数后）
3. 确认添加类型（函数、类、配置项）
```

### Step 2: 检查是否已存在类似内容
```
1. 搜索现有代码中是否有类似功能
2. 检查命名是否冲突
3. 检查依赖是否已存在
```

### Step 3: 创建新内容
```
1. 添加新函数/类/配置
2. 保持代码风格一致
3. 添加必要的import
4. 不添加多余注释
```

### Step 4: 测试新功能
```
1. 调用新添加的功能
2. 检查返回结果
3. 测试边界情况
```

### Step 5: 更新相关引用
```
1. 更新调用该功能的代码
2. 更新配置文件
3. 更新文档（如有）
```

---

## 注意事项

1. **命名检查**: 添加前检查命名冲突
2. **风格一致**: 保持与现有代码风格一致
3. **测试验证**: 添加后必须测试
4. **引用更新**: 更新使用该功能的代码
