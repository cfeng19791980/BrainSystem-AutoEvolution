# 优化流程模板

## 触发关键词
- 优化、optimize、改进、提升、改进

---

## 执行流程

### Step 1: 分析当前状态
```
1. 性能分析：响应时间、内存占用、CPU使用
2. 代码分析：重复代码、复杂度、依赖关系
3. 结构分析：模块划分、文件组织
```

### Step 2: 识别优化点
```
常见优化点:
- 性能瓶颈
- 重复代码
- 复杂逻辑
- 冗余依赖
- 不合理配置
```

### Step 3: 制定优化方案
```markdown
## 优化方案

### 优化目标
- <具体目标>

### 优化方法
1. <方法描述>
2. <方法描述>

### 预期效果
- <效果描述>
```

### Step 4: 实施优化（需备份）
```
⚠️ P3任务需请示用户确认

1. 备份原文件
2. 实施优化修改
3. 保持代码风格一致
```

### Step 5: 测试验证
```
1. 功能测试：确认功能正常
2. 性能对比：对比优化前后
3. 边界测试：检查边界情况
```

### Step 6: 记录优化结果
```
更新 memory/<date>.md:
- 优化内容
- 优化前后对比
- 优化效果
```

---

## P级别判断
- P3: 优化类任务，需请示用户确认
- 优化可能影响现有功能，必须测试验证
