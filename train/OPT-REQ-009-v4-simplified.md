## 实际优化方向

### 优化1: memory/*.md筛选规则

在生成memory/*.md时就进行筛选：

```python
# 现有流程
会话 → memory/*.md → engineer.sqlite（全量入库）

# 优化流程
会话 → 篮选(P0/P1/P2) → memory/*.md → engineer.sqlite（筛选入库）
```

### 优化2: 脱敏规则

在memory/*.md写入前脱敏：

```python
# 写入memory前
content = desensitize(content)  # API_KEY→****
write_memory(content)
```

### 优化3: 黑名单跳过

检测到黑名单关键词直接跳过写入：

```python
BLACKLIST = ['天气', '闲聊', '你好', '谢谢']

if any(kw in content for kw in BLACKLIST):
    return  # 不写入memory
```
